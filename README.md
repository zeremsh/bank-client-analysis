# Bank Client Credit Risk Analysis

**Tools:** Python · Pandas · NumPy · Matplotlib

## About
Exploratory data analysis and data cleaning of a bank client dataset.
Identified and resolved data quality issues including missing values, 
duplicate records, incorrect data types, and outliers.
Categorized loan purposes using custom text-matching logic.

## Key Findings
- Detected and cleaned 4 types of data quality issues
- Most common loan purposes: housing purchase and automotive loans
- Dataset prepared for credit risk modeling

- Exploratory Data Analysis (EDA)
- Data Visualization
